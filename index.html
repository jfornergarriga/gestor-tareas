Conexión con Google

Configura un cliente OAuth de tipo «Aplicación web» en Google Cloud, activa Google Calendar API y añade el origen de esta página a los orígenes autorizados. El identificador no es una contraseña.

Origen actual:
La conexión requiere HTTP en localhost o HTTPS. Activa Google Calendar API y configura los permisos calendar.app.created y calendar.calendarlist.readonly en Google Cloud. Añade este origen exacto como origen JavaScript autorizado.

Privacidad y tus datos

Aules se ejecuta en tu navegador. No tiene un servidor propio que almacene tus tareas.

Conexión con Google

Se solicita permiso para crear calendarios secundarios y gestionar eventos en calendarios creados por la app. Se consulta la lista de calendarios, incluidos nombres e identificadores, para localizar las asignaturas. La app no necesita leer los eventos de tus calendarios personales.

Títulos, notas, fechas, asignaturas y estados se guardan en tu cuenta de Google Calendar. El token de acceso permanece en memoria, sin guardarse en el almacenamiento del navegador. El SDK de autenticación se carga desde Google y se aplica su política de privacidad.

Datos locales

El navegador puede conservar el Client ID público y los datos introducidos en el modo de prueba. No se sincronizan. Evita información sensible en dispositivos compartidos. Puedes borrarlos desde Configuración.

Desconectar y eliminar

Desconectar elimina la sesión y las tareas cargadas de la memoria. No elimina calendarios ni revoca el consentimiento. Para revocar usa Configuración mientras estás conectado o visita las conexiones de tu cuenta de Google.

Puedes eliminar tareas desde su editor. Para eliminar todos los datos académicos, elimina sus calendarios [Aules] en Google Calendar. Revocar el acceso y borrar datos locales no elimina información guardada en Google.

Alojamiento

La app no incorpora analítica ni publicidad. El proveedor de alojamiento puede tratar datos técnicos de las visitas. Si está alojada en GitHub Pages, consulta la política de GitHub.

El repositorio público contiene código y ejemplos, no las tareas de las cuentas conectadas. Quien publique una instancia para terceros debe proporcionar su identidad y un canal de contacto en su documentación y configuración OAuth. No almacenes contraseñas ni secretos en las tareas.
